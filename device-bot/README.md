# بوت الجهاز لـ MAAI (واتساب)

يقرأ واتسابك عن طريق "الأجهزة المرتبطة" (مثل واتساب ويب)، ويرسل الرسائل لـ MAAI كل ساعة، ويرسل:
- الرد الثابت لكل شخص (مرة كل 6 ساعات، وما يرد على القروبات).
- الردود اللي ضغطت عليها **إرسال** في MAAI.
- المهام اللي وافقت عليها، وتنفّذها Grok كتابياً إذا حطيت مفتاح xAI.
- ثلاث إجراءات على الجهاز، كل واحد ببطاقة موافقة: فتح رابط، فتح ملف أو مجلد، وإرسال ملف لك على محادثتك مع نفسك في الواتساب.

> ⚠️ هذي الطريقة غير رسمية من واتساب، وفيه احتمال يحظر الرقم. الأسلم رقم ثاني أو واتساب أعمال.

## التشغيل (مرة وحدة)
1. ثبّت Node.js 20 أو أحدث من nodejs.org.
2. نزّل مجلد `device-bot` كامل إلى جهازك.
3. افتح Terminal داخل المجلد واكتب:
   ```
   npm install
   ```
   هذا ينزّل المكتبات، ومعها متصفح Chrome صغير يستخدمه البوت. يأخذ دقيقتين.
4. انسخ `.env.example` باسم `.env`، وافتحه، وعبّئ فيه:
   - `MAAI_URL`: عنوان موقعك من Render.
   - `MAAI_BOT_KEY`: المفتاح من MAAI، من بوابة المشرف ثم قسم Device bot.
   - `XAI_API_KEY` (اختياري): مفتاح Grok من console.x.ai ← API Keys (يبدأ بـ `xai-`). البوت يتحقق منه عند التشغيل ويختار موديل Grok المتاح لحسابك بنفسه، ويكتب السبب بوضوح إذا رُفض.
5. شغّل البوت:
   ```
   npm start
   ```
6. يطلع لك QR. افتح واتساب في الجوال ← **الأجهزة المرتبطة** ← **ربط جهاز** ← امسح الرمز.
7. لازم تشوف هذي الرسائل بالترتيب:
   - `MAAI reachable, key accepted.`
   - `WhatsApp linked.`
   - `Running…`

المسح مرة وحدة بس. بعدها البوت يتذكر الربط في مجلد `.wwebjs_auth`.

## إذا طلع `MAAI_URL is missing`
اكتب ملف `.env` من Terminal مباشرة بدل محرر النصوص (وبدّل العنوان والمفتاح):
- ماك:
  ```
  printf 'MAAI_URL=https://maaigit-xxxx.onrender.com\nMAAI_BOT_KEY=maai_المفتاح\n' > .env
  ```
- ويندوز (PowerShell):
  ```
  Set-Content .env "MAAI_URL=https://maaigit-xxxx.onrender.com`nMAAI_BOT_KEY=maai_المفتاح"
  ```

## التحديث تلقائي
البوت يتحقق من MAAI عند التشغيل وكل ربع ساعة: إذا فيه نسخة أحدث ينزّلها ويتأكد منها ويعيد تشغيل نفسه (النسخة القديمة تبقى باسم `bot.mjs.bak`). لازم تشغّله بـ `npm start` (يشغّل `start.mjs` اللي يعيد تشغيله بعد التحديث أو إذا توقف).

## يشتغل دايماً
- **ويندوز:** البوت يضيف نفسه لبدء التشغيل (ملف `MAAI bot.cmd` في مجلد Startup)، فيشتغل لحاله بنافذة مصغّرة كل ما تدخل على ويندوز، وينتظر الإنترنت إذا ما كان جاهز. لإيقاف هذا: أضف `START_WITH_WINDOWS=off` في `.env`.
- ما يشتغل منه إلا نسخة وحدة: إذا فتحته مرة ثانية، النسخة الجديدة تقفل نفسها.
- خلّ الجهاز ما ينام: الإعدادات ← النظام ← الطاقة ← الشاشة والسكون ← عند التوصيل بالشاحن ← أبداً (على ماك: الإعدادات ← البطارية ← منع السكون).
- على ماك أو لينكس: `npm i -g pm2` ثم `pm2 start start.mjs --name maai-bot` ثم `pm2 save` و`pm2 startup`.

## ربط واتساب
- تربطه **مرة وحدة** فقط: الجلسة محفوظة في مجلد `.wwebjs_auth`. يطلب ربط من جديد فقط إذا فصلت الجهاز من جوالك، أو جوالك ما اتصل بالإنترنت ١٤ يوم، أو انحذف المجلد.
- **بدون مسح QR:** بعد أول ربط يعرف البوت رقمك، وأي ربط بعدها يجيك برمز من ٨ حروف: يوصلك تنبيه من MAAI وتلقى الرمز في صفحة الوارد. في واتساب: الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف بدلاً من ذلك، واكتب الرمز. ولأول مرة بدون مسح: أضف `MY_PHONE=9665XXXXXXXX` في `.env`.
- إذا انفصل واتساب يعيد البوت تشغيل نفسه بعد ٣٠ ثانية بدل ما يتوقف، ويقفل أي متصفح مخفي باقي من تشغيل سابق.

## الأمان
- ملف `.env` ومجلد `.wwebjs_auth` فيها مفاتيحك وجلسة واتسابك. لا تشاركها مع أحد ولا ترفعها لأي مكان.
- البوت **ما يشغّل برامج ولا أوامر على الجهاز**: يرسل نص MAAI كما هو لشخص واحد، والمهام يجاوب عليها Grok كتابياً. الإجراءات الثلاثة (فتح رابط ويب فقط، فتح ملف أو مجلد، إرسال ملف لك أنت فقط) كل واحد بموافقتك، والملفات فقط من المجلدات المسموحة: المستندات وسطح المكتب والتنزيلات، أو اللي تحددها في `ALLOWED_FOLDERS` داخل `.env`. البرامج والسكربتات (exe, bat, ps1…) ما تنفتح أبداً، والملف يصل فقط لمحادثتك مع نفسك وحدّه ٦٠ ميجا.
- للإيقاف الفوري: من MAAI ← Admin ← Device bot ← **Disconnect**، ومن الجوال ← الأجهزة المرتبطة ← احذف الجهاز.
