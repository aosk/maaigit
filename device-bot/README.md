# بوت الجهاز لـ MAAI (واتساب)

يقرأ واتسابك عن طريق "الأجهزة المرتبطة" (مثل واتساب ويب)، ويرسل الرسائل لـ MAAI كل ساعة، ويرسل:
- الرد الثابت لكل شخص (مرة كل 6 ساعات، وما يرد على القروبات).
- الردود اللي ضغطت عليها **إرسال** في MAAI.
- المهام اللي وافقت عليها، وتنفّذها Grok كتابياً إذا حطيت مفتاح xAI.

> ⚠️ هذي الطريقة غير رسمية من واتساب، وفيه احتمال يحظر الرقم. الأسلم رقم ثاني أو واتساب أعمال.

## التشغيل (مرة وحدة)
1. ثبّت Node.js 20 أو أحدث من nodejs.org.
2. نزّل مجلد `device-bot` كامل إلى جهازك.
3. افتح Terminal داخل المجلد واكتب:
   ```
   npm install
   ```
   هذا ينزّل المكتبات، ومعها متصفح Chrome صغير يستخدمه البوت. يأخذ دقيقتين.
4. انسخ `.env.example` باسم `.env`، وافتحه، وعبّئ فيه:
   - `MAAI_URL`: عنوان موقعك من Render.
   - `MAAI_BOT_KEY`: المفتاح من MAAI، من بوابة المشرف ثم قسم Device bot.
   - `XAI_API_KEY` (اختياري): مفتاح Grok من console.x.ai.
5. شغّل البوت:
   ```
   npm start
   ```
6. يطلع لك QR. افتح واتساب في الجوال ← **الأجهزة المرتبطة** ← **ربط جهاز** ← امسح الرمز.
7. لازم تشوف هذي الرسائل بالترتيب:
   - `MAAI reachable, key accepted.`
   - `WhatsApp linked.`
   - `Running…`

المسح مرة وحدة بس. بعدها البوت يتذكر الربط في مجلد `.wwebjs_auth`.

## إذا طلع `MAAI_URL is missing`
اكتب ملف `.env` من Terminal مباشرة بدل محرر النصوص (وبدّل العنوان والمفتاح):
- ماك:
  ```
  printf 'MAAI_URL=https://maaigit-xxxx.onrender.com\nMAAI_BOT_KEY=maai_المفتاح\n' > .env
  ```
- ويندوز (PowerShell):
  ```
  Set-Content .env "MAAI_URL=https://maaigit-xxxx.onrender.com`nMAAI_BOT_KEY=maai_المفتاح"
  ```

## يشتغل دايماً
```
npm i -g pm2
pm2 start bot.mjs --name maai-bot
pm2 save
pm2 startup
```
وخلّ الجهاز ما ينام (على ماك: الإعدادات ← البطارية ← منع السكون).

## الأمان
- ملف `.env` ومجلد `.wwebjs_auth` فيها مفاتيحك وجلسة واتسابك. لا تشاركها مع أحد ولا ترفعها لأي مكان.
- البوت **ما ينفّذ أوامر على الجهاز**: يرسل فقط نص MAAI كما هو لشخص واحد، والمهام يجاوب عليها Grok كتابياً.
- للإيقاف الفوري: من MAAI ← Admin ← Device bot ← **Disconnect**، ومن الجوال ← الأجهزة المرتبطة ← احذف الجهاز.
